# Feature matrices without the thresholded proportions

Kmult-ready inputs for follow-up #5: the three pattern dimensions with
`prop_solid` / `prop_striped` / `prop_spotted` **removed**, leaving only the
continuous features. Each dimension carries a continuous measure *and* a
proportion thresholded from that same measure, so the two correlate strongly by
construction (|r| = 0.80-0.95) - the question is whether the headline result
depends on that redundancy.

**Status: run, under both tests.** Every verdict is stable without the
proportions - colour significant, stripe null, spot not significant - so the
headline result does not depend on the redundancy. Colour in fact strengthens
(Kmult BH p 0.027 -> 0.009, Z 2.20 -> 2.45), which is the expected direction:
dropping a near-duplicate feature lowers effective dimensionality without
losing information, so the test gains power. Results in `kmult_results.csv`.
